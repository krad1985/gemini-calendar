# Kairos 桌面日曆

**Google 日曆 × 待辦 × Gemini，整合進一個專為 Windows 設計的桌面日曆。**

![platform](https://img.shields.io/badge/platform-Windows%2010%2F11-blue)
![release](https://img.shields.io/github/v/release/krad1985/gemini-calendar)

## ⬇️ 下載

**[下載最新版 Kairos-Setup](https://github.com/krad1985/gemini-calendar/releases/latest)**

1. 下載 `Kairos-Setup-x.x.x.exe`
2. 執行安裝程式（不需管理員權限）
3. 登入 Google 帳號即可開始使用

安裝後內建**自動更新**——新版本發佈時，App 會自動檢查並更新。

## 功能特色

### 📅 日曆
- 多個 Google 帳號的日曆事件集中顯示
- **日 / 週 / 月三種檢視**一鍵切換：週、日為時間軸網格（重疊行程自動並排、今天紅線標示），月為經典月曆格
- 月曆檢視支援月份／年份快速跳轉、一鍵回到今天
- 點擊空白時段（週／日檢視）直接以該時間新增行程
- **常用日曆快速開關**：在設定中釘選（📌）參考用日曆（如總體行事曆、同事行程、例行會議），主畫面即可一鍵顯示／隱藏——平時淨空、預排活動時打開參考

### ✅ 待辦
- Google Tasks 清單整合
- 截止日期、今日待辦提示
- 待辦可拖曳到月曆／週曆指定日期轉成行程

### 🤖 Gemini 自然語言
- 輸入「明天下午三點跟 Amy 開會」自動解析並建立行程
- 自動判斷行程或待辦意圖

### 🔔 提醒
- **行程提醒**：30 分鐘／1 小時／1 天／1 週前，或自訂 N 分鐘前、指定日期時間
- **獨立提醒事項**：「5 分鐘後」「2 小時後」「3 天後」— 數字可自由輸入

### 🖥 桌面體驗
- 無邊框深色介面，可自由縮放、最大化，雙擊標題列切換
- 系統匣常駐、開機自動啟動
- 番茄鐘專注模式
- 內建自動更新（App 內檢查／進度／一鍵重啟安裝）
- 資料儲存於 `%APPDATA%\kairos`（舊版資料會自動遷移）

## 系統需求

- Windows 10 / 11（64 位元）
- 網路連線（Google 登入與 Gemini API）
